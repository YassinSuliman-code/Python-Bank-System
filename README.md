# Python-Bank-System

### Video Demo: https://youtu.be/mmCaVful8e4

### Description:
A command-line banking application built in Python that allows users to
create accounts, log in, deposit, withdraw, transfer funds, and change passwords.

## Features
- User authentication with validation
- Deposit and withdrawal handling with custom exceptions
- Fund transfers between accounts
- Data persistence using CSV files
- Password and username validation using regex

## Technologies
- Python
- CSV file handling
- Regular Expressions
- Object Oriented Programming

## How to Run
python project.py in the terminal window
